# Ruth Shallom — Publications Website

This repository contains the **website source** for [Ruth Shallom's research publications and software website](https://shallom-ruth.github.io/). It is not the source-code repository for the R research software described below.

## Research outputs

- **Preprint:** [Event definitions and summary statistics in published Northern Corridor transit time reports](https://shallom-ruth.github.io/paper.html). Published 20 October 2026; record version v2. Not independently peer reviewed. [Zenodo DOI](https://doi.org/10.5281/zenodo.23492442) · [Searchable PDF](https://shallom-ruth.github.io/northern_corridor_preprint_searchable.pdf).
- **Research software:** [Predictive Latency Optimization Model for Sub-Saharan Logistics Pipelines](https://shallom-ruth.github.io/software.html). Published 15 September 2026; record version v1. An R source-code software output, not a peer-reviewed paper. The R source is deposited on [Zenodo](https://doi.org/10.5281/zenodo.22770823).

The Zenodo records preserve the deposited files and DOI history. Cite each output using its own DOI; neither DOI identifies this website repository.

## Website files

The site uses static HTML and CSS hosted on GitHub Pages. It includes a searchable access copy of the preprint, a sitemap and a robots.txt file. Website availability and metadata do not establish Google or Google Scholar indexing.
